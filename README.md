# Camera Pro

Magyar Android IP-kamera kliens. Kísérleti BW4 támogatás, később közvetlen gyári protokoll. Az első kiadás szabványos RTSP/HTTP videoforrásokhoz készül; a BW4 gyári 81-es portja még nem igazolt videoforrás.

A Google Drive archiválás külön engedélyt igényel. Titkos adatok nem kerülnek a tárolóba.
